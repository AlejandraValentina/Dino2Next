# Portable N1600 confirmation evidence

All four completed original nonlinear runs are included: 101 full twelve-column
conserved fields, reference fields, execution metrics, original assessments,
GNU time reports, effective storage-adapted driver and empty rejection/limiter
streams. `manifest.json` hashes exact bytes. Source identities and the genuinely
independent complete audits reside in `../kernel_review/`; the qualified
observation and certificate reside in the parent directory.

The large full step streams are **not included**. Their hashes, sizes and original
trace manifests are preserved; the independent reviewer checked their full
content before publication. A portable replay can corroborate sampled fields,
observables and cumulative ledgers, but cannot repeat that omitted per-step
audit from this package. It must not claim otherwise. Scripts can reproduce
execution using the bound implementation tree and the software-equivalence
capsule; no numerical run is launched merely by reading this package.

This is the predefined additional-resolution evidence, not acceptance of the
whole R4/R5 battery or S06. Historical coarse failures remain failures.
