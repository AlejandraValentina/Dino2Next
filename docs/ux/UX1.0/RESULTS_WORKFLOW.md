# Results workflow

Results open with run status and provenance, then performance curves, p–θ/PV, port flow, Mach/pressure waves, temperatures, heat/energy ledgers and scavenging metrics. Users overlay runs with shared axes and selectable engineering units. Simulated and measured traces use distinct visual/source labels and cannot be merged semantically. Brake panels are disabled with `BRAKE_OUTPUT_UNAVAILABLE` when FMEP qualification is absent. Failed sweep points remain visible and are never interpolated as successful.
