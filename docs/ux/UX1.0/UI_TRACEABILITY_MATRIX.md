# UI traceability

| UI area | Schema/domain | Backend output/action |
|---|---|---|
| Engine/intake/transfers/exhaust | EngineProject revision | preflight model |
| Models | characterized resources | selected closures |
| Operating point/sweep | SimulationRequest | run/sweep |
| Performance | Result manifest | indicated/brake semantics |
| Traces | TraceSeries | p,T,flow,Mach,Y |
| Compare | parent run IDs | immutable overlay |
| Validation | ValidationResult | gate status/artifacts |

No editable control exists without this full chain.
