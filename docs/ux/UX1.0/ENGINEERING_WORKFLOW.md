# UX1.0 engineering workflow

Status: `UX1.0 — ENGINEERING_UI_BASELINE_FROZEN`.

The primary workflow is Model → Check/Preflight → Run → Results → Compare. It follows the public preparation/simulation/post-processing separation familiar from EngMod2T while presenting one coherent application. A short New Engine wizard creates identity, bore/stroke/rod, displacement/clearance, intake type, transfer count, exhaust template and initial operating point; all later editing is free navigation.
