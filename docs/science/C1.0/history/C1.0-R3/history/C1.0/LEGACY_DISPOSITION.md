# Legacy disposition

Global disposition: `SALVAGE`. Mandatory legacy code dependency: `NONE`.

| Asset | Disposition |
|---|---|
| Historical physical/numerical knowledge | PORT_CONCEPT_ONLY after C1 traceability check |
| Legacy source code and architecture | ARCHIVE_ONLY; do not import or copy |
| Canonical-test concepts | REIMPLEMENT_FROM_SPEC with independent references |
| Historical synthetic results | ARCHIVE_ONLY; no validation claim |
| Historical configurations/data | REUSE_AFTER_VERIFICATION of units, provenance and C1 domain |

Any reuse must be declared in its scope and reviewed against C1. Existing behavior is never authority.
