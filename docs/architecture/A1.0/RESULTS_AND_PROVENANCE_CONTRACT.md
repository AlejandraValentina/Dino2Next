# Results and provenance contract

Each run manifest records input/project revisions, C1/A1/UX versions, code commit, dependency lock, platform/float model, dataset hashes, initial state, mesh/time controls, retry/limiter/event counts, completion status and artifact hashes. Trace metadata declares observable definition, location, reference frame, unit and indicated/brake semantics. Simulation and measurement are distinct source kinds. Derived comparisons preserve both parent manifests.
